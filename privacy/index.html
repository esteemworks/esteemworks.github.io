Hosting on GitHub Pages

This site is hosted on GitHub Pages, a service of GitHub, Inc. in the USA, a Microsoft company. When you open a page, GitHub processes your IP address and technical data such as browser, page and time in its server logs, to deliver the site and keep it secure. The legal basis is Art. 6(1)(f) GDPR: the legitimate interest in a site that works and stays secure. GitHub may process the data in the USA. Details are in GitHub's privacy statement.

Downloads and links

The download buttons and other links lead to GitHub or other sites. There the privacy rules of that provider apply.

The apps

StartQueue and DynaTones work on your device. They collect no usage data and need no account. They contact GitHub only to look for updates, which you can switch off, and DynaTones loads its gallery from GitHub only when you open it. GitHub then sees your IP address, as with any download. Each app's privacy statement on GitHub has the details: StartQueue, DynaTones.

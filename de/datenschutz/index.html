Hosting bei GitHub Pages

Diese Seite liegt bei GitHub Pages, einem Dienst der GitHub, Inc. in den USA, einem Unternehmen von Microsoft.

Wenn du eine Seite aufrufst, verarbeitet GitHub deine IP-Adresse und technische Daten wie Browser, aufgerufene Seite und Uhrzeit. Das ist nötig, um dir die Seite auszuliefern. Ohne deine IP-Adresse kann keine Seite bei dir ankommen. GitHub speichert die IP-Adresse außerdem in Logs, um seine Dienste sicher zu betreiben, auch wenn du nicht bei GitHub angemeldet bist. Ich bekomme diese Logs nicht zu sehen.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Mein berechtigtes Interesse ist, diese Seite zuverlässig und sicher anzubieten, ohne selbst einen Server zu betreiben.

GitHub kann die Daten auch in den USA verarbeiten. Für die USA gibt es einen Angemessenheitsbeschluss der EU-Kommission, das EU-US Data Privacy Framework (Durchführungsbeschluss (EU) 2023/1795). GitHub ist danach zertifiziert.

Wie lange GitHub die Logs aufbewahrt, nennt GitHub nicht mit einer festen Frist. Nach GitHubs Datenschutzerklärung richtet sich das nach dem Zweck und nach gesetzlichen Pflichten. Einzelheiten stehen in der Datenschutzerklärung von GitHub und in der Beschreibung von GitHub Pages.

Kontakt per E-Mail

Wenn du mir eine E-Mail schreibst, verarbeite ich deine E-Mail-Adresse, deinen Namen, falls du ihn angibst, und den Inhalt deiner Nachricht. Ich nutze das nur, um dir zu antworten. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Mein berechtigtes Interesse ist, deine Anfrage zu beantworten. Geht es um deine Datenschutzrechte, ist es Art. 6 Abs. 1 lit. c DSGVO.

Das Postfach liegt bei Outlook.com, einem Dienst von Microsoft. Microsoft kann E-Mails auch in den USA verarbeiten und ist ebenfalls nach dem EU-US Data Privacy Framework zertifiziert.

Ich lösche deine E-Mail, wenn deine Anfrage erledigt ist und ich sie nicht mehr brauche. Eine E-Mail zu schreiben ist freiwillig.

Downloads und Links

Die Download-Knöpfe führen zu den Releases auf GitHub. Wenn du einen anklickst, lädt dein Browser die Datei direkt von GitHub. GitHub sieht dabei deine IP-Adresse und verarbeitet sie in eigener Verantwortung, nach seiner Datenschutzerklärung. Ich sehe auf GitHub nur, wie oft eine Datei insgesamt geladen wurde, nicht von wem.

Andere Links führen ebenfalls zu GitHub oder zu anderen Seiten. Dort gelten die Datenschutzregeln des jeweiligen Anbieters.

Die Apps

StartQueue und DynaTones arbeiten auf deinem Gerät. Sie sammeln keine Nutzungsdaten, brauchen kein Konto und geben nichts an mich oder andere weiter. Sie verbinden sich nur mit GitHub: beide, um nach Updates zu suchen, was du abschalten kannst, und DynaTones zusätzlich für seine Galerie, nur wenn du sie öffnest. GitHub sieht dabei deine IP-Adresse sowie Name und Version der App, wie bei jedem Download. Einzelheiten stehen in der Datenschutzerklärung der jeweiligen App auf GitHub (Englisch): StartQueue, DynaTones.
